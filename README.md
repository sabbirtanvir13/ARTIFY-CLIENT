# 🎨 ARTIFY – Creative Artwork Showcase Platform

> **Artify** is a modern full-stack MERN application where artists can showcase, discover, and manage digital artworks. It provides a clean, responsive, and visually engaging platform for creators to share their creativity, connect with the community, and explore inspiring artwork collections.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/sabbirtanvir13/ARTIFY-CLIENT.git
```

Move into the project directory

```bash
cd ARTIFY-CLIENT
```

---

## 2️⃣ Install Client Dependencies

```bash
cd client
npm install
```

---

## 3️⃣ Install Server Dependencies

```bash
cd ../server
npm install
```

---

## 4️⃣ Environment Variables

Create a **.env** file inside the **server** folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_uri

FIREBASE_PROJECT_ID=your_project_id
FIREBASE_PRIVATE_KEY=your_private_key
FIREBASE_CLIENT_EMAIL=your_client_email
```

---

## 5️⃣ Run the Project

### Start Backend

```bash
cd server
npm start
```

### Start Frontend

```bash
cd client
npm start
```
